# انتخاب‌گر مخاطبین بله برای اندروید

یک ابزار محلی اندروید برای انتخاب گروهی مخاطبان موجود در صفحهٔ رسمی «افزودن عضو» پیام‌رسان بله. برنامه با سرویس Accessibility کار می‌کند، CSV نمی‌گیرد، مخاطب جدید در گوشی نمی‌سازد و دکمهٔ نهایی افزودن عضو را به‌جای کاربر نمی‌زند.

> نسخهٔ فعلی: `0.3.0-beta` — حداقل Android 8 (API 26)

## قابلیت‌ها

- انتخاب هم‌زمان حداکثر ۸ مخاطب قابل‌مشاهده در هر نوبت
- ادامه از آخرین مخاطب پردازش‌شده برای هر کانال
- توقف خودکار وقتی چک‌باکس انتخاب نشود
- توقف با تشخیص پیام سقف مجاز بله
- ثبت جداگانهٔ «عضوشده»، «در انتظار نتیجه» و «ناموفق»
- گزارش تشخیصی محلی و قابل‌کپی
- بدون مجوز اینترنت و بدون مجوز دفترچه تلفن
- تأیید نهایی افزودن عضو فقط توسط کاربر در رابط رسمی بله

## دانلود

نسخه‌های قابل‌نصب فقط در بخش [Releases](https://github.com/kohansall/bale-contact-selector-android/releases) منتشر می‌شوند. برای نصب یا به‌روزرسانی، فایل APK همان نسخه را دانلود کنید.

## روش استفاده

1. APK را نصب کنید. اگر نسخهٔ قبلی نصب است، نسخهٔ جدید باید به‌شکل Update نصب شود.
2. در تنظیمات Android، دسترسی Accessibility برنامه را فعال کنید.
3. شناسهٔ کانال را وارد و «شروع انتخاب گروهی» را لمس کنید.
4. برنامه به صفحهٔ افزودن عضو بله می‌رود و مخاطبان جدید را انتخاب می‌کند.
5. فهرست را بررسی و دکمهٔ سبز «افزودن عضو» را خودتان لمس کنید.
6. به برنامه برگردید و در «ثبت نتیجه» فقط افرادی را تیک‌خورده نگه دارید که واقعاً عضو شده‌اند.

راهنمای دقیق خطای `Restricted setting` در [INSTALL_FA.txt](INSTALL_FA.txt) قرار دارد.

## ساختار پروژه

```text
app/src/main/java/com/veilaura/balequeue/
├── core/       ثابت‌های اتصال به بله
├── data/       ذخیره وضعیت، تاریخچه و گزارش محلی
├── domain/     قواعد خالص و قابل‌آزمایش متن و شناسه‌ها
├── service/    موتور Accessibility و انتخاب مخاطب
└── ui/         رابط کاربری و ثبت نتیجهٔ واقعی
```

جزئیات تصمیم‌های فنی در [معماری پروژه](docs/ARCHITECTURE_FA.md) آمده است.

## ساخت و آزمایش

پیش‌نیازها: JDK 17، Android SDK 35 و Build Tools 35.0.0.

```bash
./gradlew testDebugUnitTest lintDebug
bash tools/build_apk.sh
```

خروجی دستور دوم با یک کلید توسعهٔ محلی امضا می‌شود. کلید انتشار هرگز در مخزن نگهداری نمی‌شود.

## نسخه‌بندی و انتشار

- نسخه‌ها از [Semantic Versioning](https://semver.org/) پیروی می‌کنند.
- تغییرات روی شاخهٔ `feature/*` انجام و با Pull Request وارد `main` می‌شوند.
- هر انتشار یک Tag و GitHub Release مستقل دارد.
- APK، اثر انگشت SHA-256 و Release Notes کنار همان نسخه منتشر می‌شوند.
- روش انتشار در [راهنمای انتشار](docs/RELEASE_PROCESS_FA.md) مستند شده است.

## حریم خصوصی و محدودیت‌ها

- برنامه محدودیت یا اجازهٔ حریم خصوصی کاربران بله را دور نمی‌زند.
- برنامه تضمین نمی‌کند هر فرد انتخاب‌شده واقعاً عضو شده باشد؛ نتیجه پس از عملیات توسط کاربر ثبت می‌شود.
- تغییر رابط بله ممکن است به به‌روزرسانی قواعد Accessibility نیاز داشته باشد.
- گزارش تشخیصی ممکن است نام‌های نمایش‌داده‌شده در صفحه را به‌صورت محلی ثبت کند.

متن کامل سیاست حریم خصوصی در [PRIVACY.md](PRIVACY.md) قرار دارد.
